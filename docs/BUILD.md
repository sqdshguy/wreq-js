# Build Instructions

This guide is for developers who want to build `wreq-js` from source. If you just want to use the library, see the main [README.md](../README.md). Prebuilt binaries are installed automatically as a platform-specific `@wreq-js/binding-*` optional dependency.

## Prerequisites

1. **[Install Rust](https://rust-lang.org/tools/install)** (includes Cargo)
2. **Node.js 20+** (check with `node --version`)

That's it. The `wreq` crate handles BoringSSL internally, so no CMake or OpenSSL dev libraries are needed.

## Building

### Quick Start

```bash
npm install
npm run build
```

This runs:
1. `npm run build:rust`: compiles Rust code to `rust/*.node`
2. `npm run build:ts`: compiles TypeScript to `dist/`

### Individual Builds

```bash
# Rust only
npm run build:rust

# TypeScript only
npm run build:ts
```

### Clean Build

```bash
npm run clean    # removes dist/, rust/target/, rust/*.node
npm run build
```

## Testing

```bash
npm test
```

Runs the test runner, starts a local test server, and executes the test suite.

## Packaging and Release

The published `wreq-js` package contains only `dist/`. Each native addon ships in its own
package — `@wreq-js/binding-darwin-arm64`, `@wreq-js/binding-linux-x64-gnu` and so on —
listed in the root `optionalDependencies`, so npm resolves exactly one of them per platform
via the `os`/`cpu`/`libc` fields.

The `npm/<platform>/` directories are generated by `@napi-rs/cli` from the `napi` block in
`package.json`. Do not hand-edit them.

| Command | What it does |
| --- | --- |
| `npm run npm:dirs` | Regenerates `npm/<platform>/package.json` after changing `napi.targets` or root metadata |
| `npm run artifacts` | Fans `artifacts/**/*.node` (CI downloads) out into `npm/<platform>/`, failing if a target is missing |
| `npm run npm:version` | Stamps the root version into every platform package |
| `npm run prepublish:napi` | `npm:version` plus rewriting the root `optionalDependencies` to the current version, and validating that every platform package has its addon |

Bumping a release is therefore just `npm version <x.y.z>` — the release workflow runs
`prepublish:napi` and keeps all eight `package.json` files in lockstep. Nothing needs to be
bumped by hand.

`loadNativeBinding()` in `src/wreq-js.ts` tries, in order:

1. `../rust/wreq-js.<platform>.node` — a local `npm run build:rust`, so development always
   shadows an installed binding
2. `@wreq-js/binding-<platform>` — the published platform package
3. `../rust/wreq-js.node` — a generic locally built addon

### First-time package bootstrap

npm cannot configure a trusted publisher for a package that does not exist yet, so each
`@wreq-js/binding-*` name has to be claimed once before the release workflow's OIDC publish
can work:

```bash
npm install -g npm@latest                          # needs npm 12+, see below
scripts/bootstrap-platform-packages.sh --dry-run   # inspect
scripts/bootstrap-platform-packages.sh             # claim names + configure trusted publishing
```

This is a one-time step run from a logged-in npm account with 2FA enabled. Every release
after that is fully automated.

npm 12 or later is required: npm 11 advertises `--allow-publish` in `npm trust github --help`
but never defines the flag, so the call fails to parse, and since May 2026 the registry
requires a trusted publisher to name at least one allowed action. The script checks this
before it publishes anything. Log in interactively rather than with a granular access token —
token-based auth that bypasses 2FA is not accepted for `npm trust`.

## Platform-Specific Notes

### macOS

Install Xcode Command Line Tools if you haven't already:

```bash
xcode-select --install
```

### Linux

Standard build tools are usually sufficient:

```bash
# Ubuntu/Debian
sudo apt-get install build-essential

# Fedora/RHEL
sudo dnf install gcc
```

### Windows

- Install [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022) with C++ support
- Or use WSL2 (recommended)

## Troubleshooting

### "Cannot find module 'wreq-js.*.node'"

The Rust addon wasn't built:

```bash
npm run build:rust
```

### Rust compilation errors

Update your Rust toolchain:

```bash
rustup update stable
```

### Clean slate

```bash
npm run clean
rm -rf node_modules package-lock.json
npm install
npm run build
```
